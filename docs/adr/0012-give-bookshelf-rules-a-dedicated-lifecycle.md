# 由独立书架生命周期拥有私人集合规则

书架的私人归属、加入资格、幂等加入与移出、阅读状态推导、排序、继续阅读目标和失败恢复由独立的 `BookshelfLifecycle` 深模块统一拥有。该模块读取创作生命周期提供的公开发布事实，以及 `ReadingSession` 在完成章节时原子保存的完成证明、待续位置和“当时已完成的公开章节集合”时点事实；后者仍由 `ReadingSession` 拥有，书架只比较该事实与当前公开章节来推导“已读”或“有更新”，并为迁移前数据批量回填缺失事实。账号生命周期只负责账号安全状态，HTTP 与 React adapter 只表达书架意图，从而避免把跨领域编排散落到 route、账号模块或阅读模块中。
