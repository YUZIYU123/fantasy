# 0013：由独立生命周期拥有小雾成长规则

小雾是跨小说的平台伙伴，而不是作者内容或单部作品的一部分。羁绊、活力、雾光、奖励回执、互动冷却、收藏和失败补偿统一由 `CompanionLifecycle.execute(actor, command)` 拥有。

`ReadingSession` 只产生章节完成、节点抵达和有效阅读窗口等阅读事实，不解释奖励；章节版本完成事实按“账号＋章节＋发布版本”永久保留，并附带服务端记录时间作为重置水位。`CompanionLifecycle` 消费这些事实并幂等地更新账号养成状态。章节完成不能被奖励故障阻塞，之后观察雾庭状态时依据持久阅读事实补偿。HTTP adapter 只解析 actor 与 command，React 只渲染状态、引用领域展示常量并发送互动意图；访客试玩也通过同一个生命周期 interface 和会话存储 adapter 执行规则。

访客会话试玩完全保存在浏览器 `sessionStorage`，不调用账号养成接口、不创建匿名账号。账号导出、永久删除和小雾成长重置覆盖生命周期拥有的全部数据；重置以单调 revision 参与同一个 CAS 存储提交，原子清除成长与回执并建立新的奖励基线，避免失败时留下半重置状态、陈旧请求覆盖基线或把重置前的阅读事实重新兑换。
